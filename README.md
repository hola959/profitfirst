# Ganancia es Primero Hub

Sitio web estático en español para ayudar a fans de **La Ganancia es Primero** a implementar el método con:

- Calculadora de distribución mensual por porcentajes.
- Explicación del sistema de cuentas.
- Plan de implementación en 90 días.
- Toolkit con checklist y KPIs.

## Ejecutar localmente

```bash
python3 -m http.server 4173
```

Luego abre `http://localhost:4173`.
